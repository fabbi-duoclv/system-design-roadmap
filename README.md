Tập hợp các lộ trình học tập dạng trang web tĩnh (HTML/CSS thuần), tập trung vào **System Design** và ôn tập cấu trúc có hệ thống.

| Trang | Mô tả |
|-------|-------|
| [`index.html`](./index.html) | Ôn tập cấu trúc có hệ thống |
| [`lo-trinh-system-design.html`](./lo-trinh-system-design.html) | Lộ trình học System Design |
| [`lo-trinh-system-design-v2.html`](./lo-trinh-system-design-v2.html) | Lộ trình System Design · 12 tuần (bản v2) |

## Xem trực tuyến

Trang được deploy qua **GitHub Pages**. Sau khi bật Pages, truy cập:

```
https://<username>.github.io/system-design-roadmap/
```

## Chạy cục bộ

Chỉ là HTML tĩnh, mở trực tiếp bằng trình duyệt hoặc chạy server đơn giản:

```bash
python3 -m http.server 8000
# rồi mở http://localhost:8000
```
