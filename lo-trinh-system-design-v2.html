Phần Vol 1 và Vol 2 để trống

Vol 0 là tuyển tập bài newsletter, thứ tự ngẫu nhiên, mỗi bài 1–3 trang — đọc tuần tự thì rời rạc, nhưng tra theo chủ đề thì rất tốt. May là nó phủ gần đúng phần mà vòng phỏng vấn fullstack hay hỏi còn hai tập kia bỏ qua.

  • Mạng và bảo mật — HTTPS, SSO, lưu mật khẩu an toàn, DNS lookup
  • API — REST vs GraphQL vs RPC, pagination cursor vs offset, idempotency key
  • Trình duyệt — gõ URL rồi chuyện gì xảy ra, cách trình duyệt render
  • Vận hành — deployment strategies, container, microservices interaction
